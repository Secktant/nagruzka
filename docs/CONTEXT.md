# Текущее состояние ветки release-checks

Обновлено 2026-11-24. За основу взят последний подтверждённый релиз из main,
1.12.6 (c861f8f). Кандидат для проверок имеет CACHE 1.12.7.

- Основной агент сопровождает разработку до обкатки, затем по подтверждению
  пользователя выпускает main и проверяет возможность уборки ветки.
  [Порядок выпуска](DEPLOY.md) описывает два решения и общий адрес Pages.
- Пять ролей передают примеры, расчёты, сценарии отказа и результаты по SHA,
  см. [CODEX.md](CODEX.md). QA ведёт [каталог регресса](QA.md).
- В CI включены обновление PWA, восстановление синтетического .nz и трассы
  неудачных браузерных проверок. Файлы main сверяются с артефактом опубликованной
  и одобренной попытки по путям и SHA-256. Результаты конкретного запуска см. в Actions.
- Отчёт по предыдущим изменениям синхронизации — [SYNC-RELIABILITY.md](SYNC-RELIABILITY.md).
  Порядок установки упаковщика и восстановления — [README бэкапа](../tools/backup/README.md).
- Следующий шаг выпуска после проверки ветки — обкатка на устройстве по поручению
  пользователя. Реальный деплой и удаление веток выходят за границы задания настройки.
