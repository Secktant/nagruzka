## Поведение

- Новые разовые и рассрочки имеют локальный `createdMonth` и входят в
  «Осталось после месяца» с месяца добавления включительно.
- Для старых: поле → history create по типу/ID → первый месяц платежей.
  Для рассрочки запасная дата — минимум firstPeriod/плана/привязанных записей;
  без известных дат остаток сохраняется. Непригодная история пропускается.
- Восстановленный месяц закрепляется при сохранении и до сокращения лога.
  Даты платежей, форматы снимка/.nz/AAD/keyfile и криптография прежние.
- P1, выявленный QA: no-op save скрывал unpaid 3 000 на дате paid 2 000.
  В `64ccca9` общий preview/save-черновик сохраняет этот слот записью с прежним
  ID и пишет один снимок. Повтор, правки, перенос, отмена и reload проверены.
- Второй P1: реальный IDB abort давал reject(null), flush разрешал push и успех.
  В `04a258a` tx error/abort всегда отклоняют Error. Реальный отказ, запрет RPC,
  целый старый сейф, повтор и потерянный ответ проверены устойчивым sync-smoke.
